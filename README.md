# Para você — mini livro digital

Livro romântico responsivo em HTML, CSS e JavaScript, pronto para publicação no Vercel.

## Abrir localmente

Abra index.html em um navegador moderno. Para acessar pelo celular, publique no Vercel e abra o endereço do projeto.

## Publicar atualizações

Depois de editar os textos ou trocar imagens, envie os arquivos ao GitHub:

    git add index.html images
    git commit -m "Atualizar livro"
    git push

A Vercel publica a atualização a partir da branch main. O conteúdo é fixo no site, então todas as pessoas veem os mesmos textos e imagens.

## Alterar o conteúdo

Os textos padrão ficam no array original, dentro do script de index.html. As imagens são arquivos na pasta images; os campos image em cada página indicam qual arquivo aparece nela.
